# 🌊 AquaControl ESP32-C3

Умная система мониторинга и контроля фильтрации воды на базе микроконтроллера **ESP32-C3** с современным адаптивным веб-интерфейсом.

Проект позволяет в реальном времени отслеживать расход воды, контролировать ресурс картриджей, рассчитывать КПД мембраны обратного осмоса и обновлять прошивку по воздуху (OTA).

## ✨ Основные возможности

- **Учет воды в реальном времени:** Подключение двух датчиков расхода (YF-S201) — на входе (исходная вода) и на выходе (чистый пермеат). Расчет дренажа происходит автоматически.
- **Контроль ресурса 6 картриджей:** Визуализация остатка в виде «флаконов» с цветовой аурой (зеленый, голубой, розовый, красный), которая сигнализирует о необходимости замены.
- **Расчет КПД мембраны:** Умный расчет эффективности обратного осмоса с возможностью сброса точки отсчета (например, при замене мембраны) без потери общих счетчиков воды.
- **Статистика и аналитика:** Отслеживание расхода за сегодня, средние значения за неделю и месяц. Графики и история за последние 30 дней.
- **Web UI с поддержкой Dark/Light темы:** Интерфейс отлично выглядит как на ПК, так и на смартфоне (адаптивная верстка).
- **Защита PIN-кодом:** Критические операции (сброс ресурса, изменение настроек) защищены PIN-кодом (авто-перехват 401 ошибки на клиенте).
- **OTA-обновления:** Раздельная загрузка прошивки (`.bin`) и файловой системы (`LittleFS`) прямо через браузер с помощью ElegantOTA.
- **Энергонезависимая память:** Все настройки, ресурсы фильтров и накопленная статистика хранятся в NVS (Preferences) и не теряются при отключении питания.

## 🛠 Аппаратное обеспечение

- **Микроконтроллер:** ESP32-C3 (например, DevKitM-1).
- **Датчики расхода:** 2 шт. (YF-S201 или аналогичные, 450 импульсов/литр).
  - Вход (исходная вода) -> `GPIO 3`
  - Выход (пермеат) -> `GPIO 4`
- **Кнопка сброса:** `GPIO 5` (удержание 5 секунд — сброс Wi-Fi/настроек).

## 💻 Технологический стек

- **Бэкенд:** C++ (Arduino Framework), ESPAsyncWebServer, ArduinoJson, LittleFS.
- **Фронтенд:** Vanilla HTML5, CSS3, JavaScript (без тяжелых фреймворков, полностью работает локально с LittleFS).
- **Хранение данных:** NVS (Preferences).

## 🚀 Сборка и прошивка

Проект использует PlatformIO или Arduino IDE.

1. Установите необходимые библиотеки:
   - `ESPAsyncWebServer`
   - `ArduinoJson`
   - `ElegantOTA`
2. Соберите и прошейте прошивку.
3. Загрузите файлы веб-интерфейса (`index.html`, `app.js`, `style.css` и т.д.) в файловую систему `LittleFS`. Для этого удобно использовать плагин **LittleFS Upload Tool** в VS Code или скрипт `build_all.bat`.

**Первичное подключение:**
При первом запуске ESP32 создаст точку доступа `AquaControl_AP` (пароль: `12345678`). Подключитесь к ней и перейдите по адресу `http://192.168.4.1`. В настройках укажите данные вашего домашнего Wi-Fi (STA).
